Files in this folder:
- dungeon-437.png: 16x16 sheet of 8x8 glyphs in Code Page 437 order.
- dungeon-mode.ttf, dungeon-mode-inverted.ttf: the TrueType versions (regular and inverted).
- dungeon-extended.png, dungeon-extended.txt: the default sheet and its character list. It holds
  the dungeon.mode glyphs (CC0, above) plus glyphs added by HDG-AsciiGDX, which are also
  released under CC0 1.0 Universal.
